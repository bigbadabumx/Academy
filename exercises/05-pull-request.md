# Exercício 5: Pull Request e review

Tempo sugerido: 60 minutos

## Autor

1. Abre um Pull Request para `main`.
2. Preenche o template.
3. Explica o objetivo e a validação realizada.
4. Adiciona um colega como reviewer.

## Reviewer

1. Lê o objetivo e os critérios de aceitação.
2. Revê todos os ficheiros alterados.
3. Executa ou confirma os testes.
4. Deixa pelo menos um comentário útil.

## Autor após o review

1. Faz a alteração pedida na mesma branch.
2. Cria um novo commit.
3. Faz push e confirma que o PR foi atualizado.
4. Resolve a conversa depois da confirmação do reviewer.
