# Exercício 1: clone e exploração

Tempo sugerido: 30 minutos

## Objetivo

Clonar o repositório e compreender a sua estrutura.

## Passos

```bash
git clone <URL_DO_REPOSITORIO>
cd git-academy-python-mini
git status
git branch --all
git remote -v
git log --oneline --decorate -5
```

Depois:

1. Abre o `README.md`.
2. Identifica os módulos dentro de `src`.
3. Executa a aplicação.
4. Executa todos os testes.
5. Confirma que o `git status` está limpo.
