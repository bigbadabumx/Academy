# Exercício 2: primeira branch

Tempo sugerido: 45 minutos

## Objetivo

Criar uma branch e produzir dois commits independentes.

## Passos

1. Atualiza a `main`.
2. Cria a branch `docs/<nome>-first-change`.
3. Acrescenta o teu nome a uma secção `Contributors` no `README.md`.
4. Cria um commit apenas com essa alteração.
5. Acrescenta uma nova regra a `docs/team-rules.md`.
6. Cria um segundo commit.
7. Revê o histórico com:

```bash
git log --oneline --decorate -5
```

8. Publica a branch:

```bash
git push -u origin HEAD
```
