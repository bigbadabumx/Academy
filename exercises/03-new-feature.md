# Exercício 3: nova funcionalidade

Tempo sugerido: 60 minutos

## User story

Como utilizador, quero ver o valor médio das encomendas concluídas para compreender o valor médio de cada venda.

## Critérios de aceitação

- Criar a função `average_order_value` em `src/orders.py`.
- A função deve devolver `Decimal("0")` quando recebe uma lista vazia.
- O relatório deve apresentar o valor médio das encomendas concluídas.
- Adicionar testes para os dois cenários.
- Atualizar o `README.md` com um exemplo do novo output.

## Workflow

1. Criar uma branch `feature/<nome>-average-order-value`.
2. Implementar a função e os testes.
3. Rever o diff antes do commit.
4. Criar commits claros.
5. Fazer push e abrir um Pull Request.
