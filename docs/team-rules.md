# Regras da equipa

- A branch `main` deve estar protegida.
- Não são permitidos commits diretos em `main`.
- Cada tarefa deve ser desenvolvida numa branch própria.
- Os Pull Requests precisam de pelo menos um reviewer.
- Os comentários devem estar resolvidos antes do merge.
- O autor deve executar os testes antes do push.

## Convenção de branches

```text
feature/<work-item>-<description>
bugfix/<work-item>-<description>
docs/<description>
```

Exemplos:

```text
feature/101-average-order-value
bugfix/102-reject-zero-amount
docs/update-readme
```
